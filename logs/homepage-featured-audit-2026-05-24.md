# Homepage Featured Widget Audit — 2026-05-24

## Pre-flight
- check_invariants.py: ✅ GREEN before changes.

## Root cause
`renderFeatured()` in `index.html` fetched `/api/listings?featured=1` and on `[]` it silently set `grid.innerHTML = ''`. **But the surrounding markup kept claiming featured shows existed**:
- Section title: "Featured Shows" (static)
- Subtitle: "Verified, highlighted comedy nights in Paris" (static)
- CTA: "These shows are Featured — your show could be here →" (static)

So when the API was canonically empty, the homepage still asserted "verified, highlighted" listings — a public truthfulness failure.

Three more independent stale-copy bugs lived alongside:
- Hardcoded `May 19–25` in "Coming Up This Week" subtitle (line 337).
- "every show in Paris" overclaim in newsletter card (line 350).
- Internal JS comment `DATED SHOW INSTANCES (May 19 – June 8, 2026)` (line 375).

The `Featured Tonight` section (`display:none` by default) was already honest — only revealed when matching shows exist.
The `Featured Shows This Week` section's `renderWeeklyFeatured()` already had honest empty-state handling with a Promote CTA — left untouched.

## Stale-fallback check
No static featured cards exist in the HTML (the grid is rendered purely from API). No cached featured data in `localStorage` or `sessionStorage`. No JSON-blob fallback. The bug was the **surrounding copy**, not stale cards.

## Behavior when /api/listings?featured=1 returns []
**Before:** section title "Featured Shows", subtitle "Verified, highlighted comedy nights in Paris", empty grid, CTA "These shows are Featured — your show could be here →".
**After:** section title "Featured Shows", subtitle "No featured shows right now.", empty grid, CTA "Featured spots are open — claim one →".

Both subtitle and CTA are now rewritten by `renderFeatured()` based on what the API returns.

## Guardrails added

- 11 always-forbidden patterns (May 19–25, first 100 show runners, every show in Paris, archive-2026-04-13, verification_source, runner_email, Robert Hoehn, chucklericain, velvet-openmic, Velvet Bar Comedy — Open Mic, First 100 Featured listings).
- 2 conditionally-forbidden patterns: "Verified, highlighted comedy nights in Paris" and "These shows are Featured" — fail only when `/api/listings?featured=1` is empty.
