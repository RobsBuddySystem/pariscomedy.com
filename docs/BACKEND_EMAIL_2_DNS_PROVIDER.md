## Provider decision: Postmark

**Why Postmark:**
- GDPR-compliant; EU data residency option available
- Dedicated transactional stream (not mixed with marketing mail)
- Magic-link delivery optimized — strong deliverability reputation
- Free tier: 100 emails/month (sufficient for early user base)
- SPF/DKIM auto-provisioned per server; simple domain verification
- Well-supported Python SDK + webhook support

**Alternatives documented:**
- Resend — developer-friendly, EU region, but newer reputation pool
- Mailgun — mature, EU region, more complex pricing
- Amazon SES — cheapest at scale, requires more DNS setup + warm-up period

## DNS verification checklist (operator runbook)

1. Log in to Postmark → Sender Signatures → Add domain `pariscomedy.com`
2. Postmark generates DKIM TXT → add `pm._domainkey.pariscomedy.com` in Cloudflare
3. Add SPF TXT to `pariscomedy.com` (merge with existing SPF if any)
4. Add DMARC TXT to `_dmarc.pariscomedy.com`
5. Add bounce CNAME `pm-bounces.pariscomedy.com → pm.mtasv.net`
6. Click "Verify" in Postmark dashboard
7. `dig TXT pariscomedy.com | grep spf` — confirm SPF
8. `dig TXT pm._domainkey.pariscomedy.com` — confirm DKIM
9. `dig TXT _dmarc.pariscomedy.com` — confirm DMARC
10. Send test email via Postmark API with test token
11. Verify delivery + spam score
