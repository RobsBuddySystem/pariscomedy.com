How this page works

This is meant as a useful public reference, not a gatekeeping list. If a show has no verified activity in the last 6 months, it comes off the current directory until we can verify it again.

If something is wrong, missing, or newly launched, send it to Chuck via the Paris Comedy contact form. Verified fixes get added to the public data layer; uncertain items go into manual review instead of being guessed.

Grouped by venue · working links · show runner if known · updated from the public data layer · corrections reviewed by Chuck
